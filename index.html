01 / What I work on

Data platforms & distributed systems

At Amazon Ads, I work on data lake systems. My interests include Apache Iceberg, Spark, and treating schemas as code to make data evolution more reliable. Previously, I worked on AWS Connect Customer Profiles and Fulfillment Operations.

Agentic applications & useful knowledge

I explore RAG, MCP, and knowledge graphs: how agents retrieve the right context, connect information, and help engineers solve practical problems. Java is my home base; Python is a frequent companion.
